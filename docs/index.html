About

プロフィール

アイデアを、動くプロダクトに。
AIと共に作るデベロッパーです。

  • 得意なこと：ゲーム・開発ツール・SEOコンテンツの高速プロトタイピング
  • 好きな言語：JavaScript と Rust
  • 学習中：実践的な Rust とAI開発ワークフローの自動化

Claude Code × AI開発を中核に据え、Antigravity IDE という独自の開発環境を構築しています。 カスタム Skills・SubAgents・Commands を組み合わせることで、定型作業を自動化し、創造的な部分に集中できる環境を整えています。

ブラウザゲームのようなインタラクティブな実装から、検索意図に沿った構造化SEO記事の生成、 開発を支援するツールまで——分野を横断して「AIで素早く形にする」ことを得意としています。

技術は手段。最終的に価値を届けるプロダクトを、スピードと品質の両立で生み出すことを目指しています。
